# Product

## Register

product

## Platform

web

## Users

General public browsing for verified Islamic speakers, ustaz/ustazah, and pendakwah across Malaysia. Secondary audience: event organizers and mosque committees who need to discover and contact speakers.

## Product Purpose

ilmu360° connects the Muslim community with verified, knowledgeable Islamic speakers and their upcoming events. It exists to make finding trustworthy religious teachers as reliable as looking up any other professional directory. Success means a user can confidently find a verified speaker, see their credentials and upcoming majlis, and attend with trust.

## Positioning

The trusted, curated directory of verified Islamic speakers — every profile reviewed, every event public.

## Brand Personality

Trustworthy, warm, scholarly. The interface should feel like a respected reference — authoritative without being cold, inviting without being casual.

## Anti-references

- Generic SaaS blue/gray dashboards (the platform should feel distinctly Islamic in aesthetic)
- Overly trendy or gamified UI that undermines scholarly credibility
- Cluttered, ad-heavy directory sites common in religious listings
- Dark patterns or urgency tricks (the trust is earned, not manufactured)

## Design Principles

1. **Trust through verification** — every verified profile and public event signals safety. The UI should make verification visible without being loud about it.
2. **Clarity before density** — information-rich profiles (bio, credentials, event history) must remain scannable. Progressive disclosure is the tool, not truncation.
3. **Warm authority** — the visual language (emerald, gold, warm neutrals) reflects Islamic scholarly tradition. The interface is polished but not sterile.
4. **Community-powered accuracy** — public contributions and corrections keep the directory current. The contribution flow should feel like participation, not bureaucracy.
5. **Respect the reader's time** — search-first architecture, fast navigation with wire:navigate, and minimal friction to find what matters.

## Accessibility & Inclusion

WCAG AA target. Supports reduced motion, keyboard navigation, and screen readers. Malay language primary interface with English fallback.
