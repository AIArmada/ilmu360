# ilmu360° Brand Name Standard

**Official naming rules and usage contract**  
**Document type:** Brand guidance standard  
**Brand:** ilmu360°  
**Status:** Binding brand-name usage guide

---

## 1. Purpose

This document defines the official naming system for **ilmu360°**.

It governs how the brand name must be written, displayed, spoken, typed, and used across all public, formal, digital, technical, legal, marketing, and internal contexts.

These rules exist to protect brand consistency, readability, searchability, and long-term identity.

---

## 2. Official Brand Name

The official public brand name is:

# **ilmu360°**

This is the master brand identity.

It must be used in all primary brand expressions, especially where the brand is presented visually.

---

## 3. Official Name Variants

Only the following name variants are approved.

| Variant | Status | Purpose |
|---|---|---|
| **ilmu360°** | Official primary brand identity | Logo, visual identity, campaigns, public brand moments |
| **ilmu360** | Official functional spelling | Domain, URLs, handles, hashtags, systems, code, plain text |
| **Ilmu360** | Official formal spelling | Legal, official documents, institutional correspondence |

No other spelling variant is approved.

Previous-name references are not part of the active brand system and must not be used in routine product, marketing, instructional, or public communication.

---

## 4. Master Rule

The brand must follow this hierarchy:

> **ilmu360° = brand identity**  
> **ilmu360 = functional spelling**  
> **Ilmu360 = formal spelling**

This hierarchy must be followed across all materials.

## 9. Capitalization Rules

### 9.1 Brand identity must be lowercase

The primary visual brand must always be written as:

```text
ilmu360°
```

The first letter must remain lowercase in brand identity usage.

### Correct

```text
ilmu360°
```

### Incorrect

```text
Ilmu360°
ILMU360°
Ilmu360
ILMU 360°
```

### 9.2 Formal spelling uses capital I

In official prose, the first letter may be capitalized:

```text
Ilmu360
```

This is only for formal text use. It is not the default logo or visual identity.

### 9.3 All caps is prohibited

The brand name must not be written as:

```text
ILMU360
ILMU360°
```

All-caps usage is prohibited except where an external system automatically capitalizes text and cannot be controlled.

## 10. Degree Symbol Rules

### 10.1 Degree symbol is part of the visual brand identity

The degree symbol **°** must be used in the primary brand identity:

```text
ilmu360°
```

It visually reinforces the meaning of 360: ilmu around us, complete access, all directions, full-circle impact.

### 10.2 Degree symbol must not be used in functional spelling

The degree symbol must not be used in:

- Domain
- Email
- URL
- Hashtag
- Handle
- Code
- File names
- Database values
- App identifiers
- API identifiers
- Analytics names
- Plain technical text

### Correct

```text
ilmu360.com
#ilmu360
@ilmu360
```

### Incorrect

```text
ilmu360°.com
#ilmu360°
@ilmu360°
```

### 10.3 Degree symbol must not be replaced with words

Do not write:

```text
ilmu360degree
ilmu360degrees
ilmu360 darjah
ilmu360-darjah
```

The approved visual symbol is **°**.  
The approved functional spelling is **ilmu360**.

## 28. Governance Rule

Any new use of the brand name must follow this document.

Before publishing any new material, check:

1. Is this a visual brand moment?  
   Use **ilmu360°**.

2. Is this a technical, typed, searchable, or system context?  
   Use **ilmu360**.

3. Is this a formal or legal document?  
   Use **Ilmu360**.

4. Is this an archival or legal provenance exception?  
   Keep prior-name reference out of the main narrative unless it is strictly required.

5. Is any unapproved spelling being introduced?  
   Remove it.
