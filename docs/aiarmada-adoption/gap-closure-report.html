North star

  • Maximum native package use — package contracts, models, actions, and tables are the default path.
  • No backward compatibility layers at exit — hard cuts; update clients, tests, MCP, and docs in the same change set.
  • No dual systems — one store, one write path, one index path per domain concept.
  • No hacks / shortcuts — delete builder maps, alias traits, legacy accessors, dual-mode flags.
  • Intentional custom only — Institution/Speaker, donations, public UX, MCP, Islamic presentation, FCM/WhatsApp adapters.
  • Accept total rewrites of any surface that only exists to paper over the old app.
  • Performant, stable, long-term — green migrate/seed, focused tests, PHPStan on touched code, readable models.
