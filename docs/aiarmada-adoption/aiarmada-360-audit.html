Executive Read

The application is already strongly package-backed in events, membership, addressing, contacting, engagement, signals, and multiple Filament plugins. The real drift risk is not “no adoption”; it is mixed ownership: wrappers, compatibility vocabulary, and large local config shadows sitting on top of native package runtime.

The most important unresolved gap is communications. The package owns inbox tables, resolver contracts, admin resources, and webhooks, but the app still owns most notification orchestration. The second major gap is latent commerce capability: inventory, seating, and ticketing are live in admin/runtime but thin in product code.

The report treats Graphify as an installed analysis tool. Evidence: AGENTS.md contains Graphify instructions and graphify-out/GRAPH_REPORT.md is present. Graphify is used for codebase understanding, not as an application runtime package.
