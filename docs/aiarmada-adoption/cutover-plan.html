Rules For Parallel Execution

RuleDetail
1. Lock shared filesParallel work is allowed only when shared files are lock-managed. Hotspots include AppServiceProvider, routes/api.php, config/scout.php, and EventSearchService. Serialize edits on each hotspot.
2. Claim before workUpdate the tracker table above with your name and set status to "In Progress" before touching any files. Commit with the WU number in the message: WU3: collapse SavedSearch wrapper — caller migration.
3. Verify before unclaimRun the WU's verify tests. If they pass, update the tracker to "Done" and mark the checkboxes. If they fail, fix before moving on.
4. Phase gatingDG1/DG2 decisions must be explicit before implementation. WU12A must complete before WU12B. WU17 runs only if DG2 approves paid-commerce activation.
5. Compatibility edges onlyDo not add implicit legacy bridges. Compatibility aliases are allowed only at explicit v1 API edges, must be documented as deprecated, and must have a removal date.
6. Package firstPrefer imports from AIArmada\*. Keep App\Models only for minimal, logic-bearing extensions (for example media/auditing/casts), not field-alias wrappers.
