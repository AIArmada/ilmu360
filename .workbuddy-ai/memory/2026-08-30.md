## Gotchas discovered

- **Labels are translated at render time.** `resources/lang/en.json` maps `Penceramah` →
  `Speaker`, so `assertSee('Penceramah')` fails under locale `en` even when the Malay key
  renders fine. `config('app.locale')` defaults to `ms`, but `EventSearchTest`'s
  `describe('Event Search Filters')` forces `en` in `beforeEach`. Check `resources/lang/*.json`
  (NOT `lang/`, which only has framework strings) before asserting on translated copy.
- **Scramble (OpenAPI docs) is at the edge of the 512M test memory limit.** `phpunit.xml` sets
  `memory_limit=512M`. `EventController::index()` is a ~416-line method holding every
  `AllowedFilter::callback` inline; Scramble reflects over its source, and adding ~25 more
  lines inline made `ScrambleDocsTest` OOM. **Fix: extract the filter body into a private
  helper** (matching the existing `applyPrayerTimeGroupFilter` / `applyDhuhaPrayerTimeFilter`
  convention) so the code moves out of the reflected method. Do not just raise the limit.
- `it filters gender through the package audience relation` is a **pre-existing flake**
  (verified failing on a clean `git stash` baseline). Do not weaken its assertion.
- `ScrambleDocsTest.php:786` fails at baseline too — pre-existing.

## IP-based default country (Cloudflare CF-IPCountry) + geography-provider cascade

- Added `config/location.php` — operator-controllable geo config: `geoip.enabled`
  (default true), `geoip.header` (default `CF-IPCountry`), `geoip.indeterminate_codes`
  (`XX`, `T1`), `default_country_code` (env fallback to `CONTACTING_DEFAULT_COUNTRY_CODE`,
  default `MY`).
- Added `app/Support/Location/VisitorCountryResolver.php` — shared resolver extracted from the
  inline /institusi CF logic. Public API: `resolve(): ?string` (country UUID),
  `resolveCode(): ?string` (ISO2), `resolveWithSource(): array{country_id,country_code,source}`
  (source ∈ `edge_header`|`app_fallback`|`unresolved`), `forget()`. Octane-safe memoization via
  `ensureCacheScope()` keyed on `spl_object_hash(app()).':'.spl_object_hash(request())`.
- **Trust caveat:** only trust `CF-IPCountry` when the app is reachable solely through Cloudflare.
  Forged headers that don't resolve to a real seeded country fall back to the configured default
  (so `CF-IPCountry: ZZ` won't break scoping). `XX`/`T1` = indeterminate → fall back.
- `/majlis` (`App\Livewire\Pages\Events\Index`): `mount()` calls `applyDefaultCountryScope()`
  before normalizing URL state; `clearAllFilters()` re-applies the visitor country so "clear"
  returns to the natural scope, not all-countries. View computes
  `$hasCountryScope = filled(country_id) && country_id !== defaultCountryId` so the auto-scope is
  NOT shown as an active filter chip.
- `/institusi` (`resources/views/components/pages/institutions/⚡index.blade.php`): replaced
  ~35 lines of inline CF logic with the shared resolver (`defaultCountryId()` delegates to
  `VisitorCountryResolver::resolve()`).
- Geography-provider expansion is automatic: defaulting the country to MY is enough —
  `SharedFormSchema` + `CountryAddressProfileResolver` reveal the district/subdistrict selects via
  `visible()` guards once state/district are chosen. No extra code needed on /majlis.

## Test helpers gotcha (addressing)

- Use `ensureTestMalaysiaCountry()` / `ensureTestAddressCountry('SG','Singapore')` from
  `tests/Pest.php` (global, always in scope) for geography fixtures. Do NOT use
  `ensureMalaysiaCountryForTests()` — it is local to `tests/Feature/EventSearchTest.php` and is
  out of scope in other test files (caused `Call to undefined function` on first run of
  `DirectoryAddressCascadeTest`).
- The subdivision field `Bandar / Mukim / Zon` only reveals AFTER a district is selected (cascade
  state→district→subdivision). When asserting the subdivision label in a cascade test, set
  `filterData.area_assignments.administrative_district` before `assertSee('Bandar / Mukim / Zon')`.
